# 状态与事务补充规格

此文件不是应用实现。所有参数引用 product-config.json；不得在组件中另写不一致的常量。

## 生效状态

`persistentPreference`为本演示长期设置，不是平台模型；`sessionOverride`是字段级覆盖。freshness/positiveTagIds为null时继承长期；空数组表示明确空集合。少推为本次与长期两桶的去重并集，惩罚按最大值而不是数量累加；同tag正负冲突必须让用户解决。普通行为不直接改这些显式字段。

每次打开根编辑器，复制有效显示值到draft，同时初始化dirtyFields为空。默认writeScope=session，与用户已有长期值的显示无关。返回/完成子页不提交；根取消丢弃。提交只保存用户实际改动且与基线不同的字段。仅切scope而没有内容或保护变更，不得启用确认。若用户希望把已生效的本次方案长期保存，切到长期后另显示“保存当前差异到长期”确认项，列出与persistent不同的方向/少推项；用户明确选择后这些字段才计入dirtyFields，最终仍由总面板确认。没有差异时不展示此项。改变保护本身属于有效变更，但不是给长期偏好写默认字段。

进入长期管理前若有脏稿，应询问是否放弃；默认留在编辑器。管理是独立事务，有自己的确认/撤销，不让根取消回滚已提交管理操作。黑名单首版只读预置；不能造一个假的可编辑系统。

长期写入freshness或positiveTagIds时，在同一事务中清除对应sessionOverride字段，使新设置立即可见；长期添加少推时移除同对象的会话重复项。所有冲突检查针对拟提交后的完整有效状态，包括旧长期少推与新会话正向标签，不只检查输入patch。发现旧负向冲突时不能隐式删除长期少推；应让用户取消当前选择，或先进入长期管理明确移除。

## 幂等与两阶段结果

每次有效提交创建operationId、baseRevision、dirtyFields、beforePatch。重试同一操作复用ID；版本冲突保留草稿并重新核对，不last-write-wins覆盖。状态应用成功返回appliedRevision；推荐刷新是第二阶段，使用requestId+revision。刷新失败只能说“设置已保存，推荐尚未刷新”。旧结果不能覆盖新版本。

支持撤销最新相关调整。用反向patch恢复其字段，不重置全部状态；若相关字段此后变更，明确冲突，不应用旧快照。独立红心与播放进度不撤销。临时保护期间已排除事件不因撤销开关而回填。提示条10秒后消失，但当前状态中仍能撤销上次，直到下一次相关变更或会话结束。

## 会话

首次确认一个会话级偏好建立startedAt；以后修改不延长4小时上限。lastListeningActivityAt来自受控播放器的播放/播放心跳，不由随意浏览页面刷新。连续播放不算闲置；暂停且30分钟无播放活动结束R03覆盖，恢复项目长期设置。达到4小时也结束R03覆盖。

保护独立为off / active / review_required。active达到30分钟闲置或4小时进入review_required，仍受保护。用户“继续4小时”新建提醒周期；“关闭”只对之后事件放行。提醒展示在推荐页/播放页/迷你播放器，不自动打断播放。关闭页面/系统杀进程不能当成可靠的关键事件；恢复时检查存储时间戳。

生产设备恢复状态不明时，先隔离；不能先上报为可学习再试图撤回。Demo仅保证同标签页刷新恢复虚构状态，新标签页是独立演示，不模拟真实账户同步。

## 事件分片

时长在曲目变化、保护状态变化、播放/暂停/结束时切片；片段 [startAt,endAt) 互不重叠。保护开启前的片段不追溯排除（事后控制归R05），开启后的片段不能学习；关闭后的新片段可以恢复。按事件发生时的设备状态判定，不能按批量上传时状态统一回填。

搜索、歌单、每日推荐、心动、私人漫游是来源标记，不要因打开不同页面给原播放队列重标来源。来源覆盖未知音乐事件先隔离。播客、直播、投屏与外部播放器不在首版模拟覆盖承诺中。

## 排序约束

应用PRD§07固定公式，先过滤playable与预置黑名单。正向匹配为命中正向标签比例，没有标签则0；新鲜度使用虚构novelty而非发布时间；少推命中任一对象惩罚一次。相同分按trackId升序。不加入随机打散、线上模型、曲库搜索或未说明的动态权重。

rank fixture中的expectedScores由规格计算生成，是测试输入，不是已执行的应用测试。不得为了通过fixture改动产品文案或权限逻辑。

## 角色与降级补充

用户决定内容/影响范围，客户端维护草稿、对象快照、幂等ID与焦点返回；偏好层负责版本校验及原子应用，推荐侧按对应版本生成后续队列；行为/画像侧按发生时间切片并执行隔离。数据侧做事件去重与缺失率检查，实验/运营侧固定分桶、只看聚合指标，异常时停止错误写入。日志失败不阻断播放，推荐失败不回滚已经确认的保护。

非当前音乐、无可靠来源或保护状态不明确的事件不默认学习。纯音乐演示记录不同时附加歌词语种标签。默认统计日界为账号固定时区，缺失统一Asia/Shanghai并记录；频率的28天与强度的全音乐活跃日分母不能混用。
