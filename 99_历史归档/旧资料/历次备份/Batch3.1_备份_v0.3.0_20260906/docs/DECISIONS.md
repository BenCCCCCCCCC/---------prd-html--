# 产品决策记录

所有条目由本轮助手提出并写入规格；项目负责人已批准用于 Batch 2 本地 Beta。它们不是网易内部决定。规则变更必须同时更新PRD、HTML规格、配置、用例与本表。

| ID | 决策 | 理由与代价 |
|---|---|---|
| D01 | 研究定位为假设驱动；不写真实回收数 | 用户确认无原始数据；不能让求职叙事超出证据 |
| D02 | 意图、熟练度、频率、时长、生命周期与情境分轴 | 防止用高低频替代真实需求分析；增加数据口径管理 |
| D03 | R03/R04首版；R05/R06不实现；R07可移除 | 控制范围，避免把多个未经验证需求一起打包上线 |
| D04 | R03作用于推荐来源队列；R04跟随受控设备播放 | 解决页面范围和数据范围不是一回事的问题 |
| D05 | 本次少推不写长期；长期选择只保存本轮脏字段 | 防止越权和默认值覆盖长期偏好 |
| D06 | 保护到期进入待确认仍保护 | 不悄悄恢复学习；代价是可能需要额外一次确认 |
| D07 | 30分钟/4小时/30秒、标签3项为演示/初始参数 | 提供可实现的规格，未假装有内部最佳阈值 |
| D08 | 软少推、只读黑名单集成、R05事件排除分别建模 | 防止“少推=屏蔽=删除画像”的混淆 |
| D09 | 设置保存与推荐展示分两阶段 | 网络失败时能真实说明状态；实现需版本和幂等 |
| D10 | 撤销使用字段patch；不追溯回填受保护数据 | 用户控制优先；不是时光倒流，也不回滚独立操作 |
| D11 | R07默认本地规则模拟，无假置信度 | 可靠、无模型成本；代价是不能宣传已证明LLM效果 |
| D12 | AI输出候选，无直接执行权；范围与保护仅建议 | 降低越权风险；需要用户再次确认 |
| D13 | 调整后指标仅诊断；正式实验另用随机分组主指标 | 避免自选择偏差；需真实平台数据才能执行 |
| D14 | 原播放器结构保留，公开资产换虚构内容 | 保留产品上下文；避免默认传播真实音乐资产 |
| D15 | 白字主按钮使用深红#D92D3A | 保留红色识别与可读性，不无条件复制旧稿颜色 |
| D16 | 项目专属skill、Token、截图门槛约束Codex | 不把“审美好”当一句提示；需要实际截图回传 |
| D17 | 真实API/发布/付费/用户数据公开单独授权 | 不因项目交付请求默认开启外部服务或公开资料 |
| D18 | PRD 与 HTML 显示主要未采用/延后方案、选择标准、代价和反转条件 | 为研发评审和面试深挖保留决策依据；代价是需要控制页面信息密度 |
| D19 | 长期提交后立即清理同字段会话覆盖，并基于合并后状态检查冲突 | 避免“已保存但界面仍显示旧会话值”；代价是需要字段级合并与明确确认 |

## D19｜长期写入必须立即可见
长期提交对应字段时清理旧会话覆盖；以合并后有效状态检查冲突。把当前本次方案转长期需要明确勾选保存差异，不能因改变scope就保存默认值。
