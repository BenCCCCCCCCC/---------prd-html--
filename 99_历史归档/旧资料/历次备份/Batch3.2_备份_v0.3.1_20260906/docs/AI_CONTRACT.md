# R07 输入输出契约 v0.5

状态：规格，未实现解析器或调用模型。与 PRD §13、HTML §07 配套。

## 边界

公开默认适配器叫 `local_rule_preview`，界面持续显示“规则模拟，未调用真实模型”。它只覆盖 tags.json 中的词汇、明确否定及少量已定义句式；不会对任意自然语言作可靠理解承诺。真实模型是未来可替换适配器，不改变产品规则。

`parse(request) -> envelope`：信封由应用创建，含 requestId、draftRevision、adapterMode、transportStatus(ok/error/cancelled)、candidate 或 errorCode。模型只返回 candidate，不能生成应用权限或 operationId。requestId/draftRevision由调用方验证；过期响应直接丢弃。

- Request：`specs/intent-request.schema.json`。
- Candidate：`specs/intent.schema.json`（供应商无关的 JSON Schema Draft 2020-12）。
- 字典：`specs/tags.json`。
- 范围与参数：`specs/product-config.json`。

## 字段语义

`null`表示用户没有提出修改，必须保留现有草稿值。`positiveTagIds=[]`仅在明确清空时替换本轮目标范围的正向标签。`negativeTargets=[]`仅在明确清空时移除目标范围的少推项；不是清除黑名单。非空negativeTargets是待添加对象，按kind+id去重；手动每次1项，AI每次最多3项，每个范围最多10项。超限必须告知，不截断。

非空positiveTagIds为替换本轮方向的候选集合，采用前必须显示“原来 → 建议”差异，不能让用户误以为只添加了一项。scopeSuggestion/isolationSuggestion不进入自动应用patch；原草稿范围与保护开关保持不变，只在预览中提示去P07手动选择。仅范围建议且没有内容修改时，不得伪造一次偏好提交；用户仍可自行修改P07中的临时状态。

ready候选必须包含至少一项实际字段修改或范围/保护建议；全null且无建议的候选属于无有效操作，不显示“采用”。ready只代表允许呈现待确认候选，不代表已执行、更不代表模型一定理解正确。needs_clarification/unsupported的patch全部null，禁止采用，提供具体澄清与手动路径。空字符串/超过200 Unicode码点的输入在解析前拒绝；无上下文的“当前音乐人”等不可猜测。

## 校验顺序

1. 输入大小/空值/纯文本；截去首尾空白后再检查空值。不要以切片方式静默截断超过200字输入。
2. JSON结构、必填、额外字段、枚举和数组上限。
3. 字典与实体归属；track/artist应存在于给定曲库，引用“当前”必须与打开时上下文一致。
4. 领域规则：同tag正负冲突；同对象重复去重；不得解除黑名单；软偏好不能谎称严格过滤。
5. 权限：AI永远不调用执行/长期画像/删除/账户工具；范围与保护仅建议。
6. 语义评估与用户预览：是否丢失否定/时间范围/关键条件。静态校验不能穷尽此层，不能用结构通过率代替语义正确率。
7. 用户采用候选 → 只改根草稿 → 用户最终确认 → 产品执行层做原有校验与写入。

## 评估设计

40条合成规格用例：前30条供开发理解，后10条作预留回归。它们都在公开规格包中，不构成独立盲测集，也不证明模型泛化能力。未来冻结Prompt/字典后，需另采真实同意授权的输入或由独立评审编写未泄露用例。

先按正向、负向、范围、清除、歧义、否定、未知实体/标签、权限、注入、输入边界逐类看结果。记录结构合规率、字段精确匹配与语义保留（人工核对）、错误执行数、正确澄清/拒绝率。权限错误要求0；开发用例的目标是逐例通过，而非对外宣传100%准确。

澄清问句与拒绝文案按含义和下一步路径审核，不做整段文本逐字匹配；字段与枚举按契约精确比对。

产品评估另与手动选择比较：完成时间、理解正确、修正次数、取消、最终范围误选。真实模型上线还需记录模型/Prompt/标签/schema版本、端到端P50/P95、输入输出量与实际成本。没有模型执行时全部标“未测”，不填0ms、0%错误来营造好结果。

## 未来真实模型的入口条件

供应商的严格结构化输出只支持JSON Schema子集，须在接入时核验/转换本契约；不保证可直接把本文件原样发送到任意API。[W06]

未来默认总时间预算8秒、单次最多5秒、最多一次受限重试（剩余预算不足不重试），均是待测试初始参数。超时/拒绝/格式错误回手动；当前不实现调用。正式接入必须有服务端密钥、预算上限、速率限制、输入最小化和停用开关。禁止在浏览器或提交仓库中保存密钥。
